# 次元语音伙伴 · 第1课起步

1. 在 PyCharm 里用「打开」选中这个文件夹。窗口最下面靠右是解释器，选装了 Anaconda 的那一个。
2. 学和练的题目在 `cases` 文件夹。伙伴类写在 `characters.py`，三位伙伴登记在 `services.py`。要写的代码看文件里标着 TODO 的备注。
3. 运行 `app.py`，浏览器打开 http://127.0.0.1:5000 。提示 No module named 'flask' 时，在 PyCharm 底部的 Terminal 里运行 `pip install flask`。
4. 写完右键运行 `自查.py` 对一下。每一段写对时页面上什么样、钥匙填在哪，看 `指导书.md`。
