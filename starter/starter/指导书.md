# 第1课实验指导书 · 次元语音伙伴

## 实验目标

先做学和练，学会用 class 写一个类，用 `__init__` 和 self 让每个对象记住自己的数据，再写方法、类属性和 `__str__`。
然后把这些写进语音伙伴：写出伙伴类 Character，造出傲娇酱、元气酱、学长三位。点谁谁打招呼，聊天时会回话、会涨好感。

## 今天要用的知识

类和对象、class、实例化、构造方法 `__init__`、self、实例属性、普通方法、类属性、`__str__`、析构方法 `__del__`、对象放进列表和字典。

## 学和练

题目在 `cases` 文件夹。每道题开头写了要做成什么样、运行后应看到什么。写完右键运行，和题目里的样子对一下。做完再打开同名的 `_答案.py` 对照。

| 题目 | 做成什么样 | 用到的知识 |
| --- | --- | --- |
| 学1 娃娃机 | 两台娃娃机各投各的币、各抓各的，第 3 次必中一只 | class、实例化、`__init__`、self、实例属性、方法 |
| 学2 共享单车 | 三辆车各打一行骑行记录；周末涨价所有车一起变，校队车单独免费 | 类属性和实例属性、`__str__`、对象放进列表、实例上的同名属性 |
| 练1 自习室占座 | 占座时空位减 1，删掉座位票时空位加回来，闭馆时回到 50 | 析构方法 `__del__`、del |
| 练2 宿舍洗衣房 | 三台洗衣机按编号取出来开洗，过 35 分钟看谁洗好了，今天收入 16 元 | 方法里调用方法、对象放进字典 |
| 作业 篮球计分板 | 两节打完是 5 : 8，经管领先 | 类、方法、`__str__` |

## 语音伙伴

在 PyCharm 里用「打开」选中整个 starter 文件夹，运行 `app.py`，浏览器打开 http://127.0.0.1:5000 。
这一课改 `characters.py` 和 `services.py`。`app.py`、`ai_lab.py`、`iflytek_kit`、`templates`、`data` 已经写好，不用改。
每一段要写的代码，看文件里标着 TODO 的备注：页面上哪里会变、要做的事、写对时的结果。

| 难度 | 写什么 | 写对时页面上 |
| --- | --- | --- |
| 基础 | characters.py：类属性 count 和 `__init__` | ROLES 登记好以后，顶上显示「已登记 3 位伙伴」 |
| 基础 | services.py：ROLES | 左边出现傲娇酱、元气酱、学长三张卡片 |
| 基础 | characters.py：greet | 点一位伙伴，聊天框里出来「我是傲娇酱，……」，还会念出来 |
| 进阶 | characters.py：respond | 发「夸夸我」有回话，♥ 加 10，最多 100 |
| 进阶 | characters.py：`__str__` | 名字下面的名牌是「傲娇酱 / 哼，才不是特意来陪你呢！」 |
| 挑战 | characters.py：recall | 点 📜，伙伴说出你们聊了几句、你最后说的是什么 |

写的顺序：先写 `__init__` 和 ROLES，左边就有伙伴；再写 greet，点谁谁打招呼；然后写进阶和挑战。

每写完一段：保存，在运行窗口点红色方块停下 app.py，再点绿色三角形重新运行，浏览器刷新。
右键运行 `自查.py`。每一行前面标着基础、进阶、挑战，最后分开数，你做到哪一档，就看那一档是不是全对。

检查 respond 和 recall 时不要勾 ✨AI：勾上以后回话由星火给出，不经过你写的 respond，♥ 不加 10，history 也不记。

写完以后点 ♥ 旁边的「直接改成 999」，好感真的变成 999，比上限 100 还多。在类外面谁都能改好感，这个数就不可信了。

页面上的「＋ 自建伙伴」要用 check_name 和 from_dict，这两个方法是第2课的挑战题。第1课点它，页面会提示还不能造。

## 出错时看哪里

- 一运行 app.py 就停下：看运行窗口里 Traceback 最后几行，写着错在哪个文件、哪一行。
- 页面提示没打招呼或没回出话：运行窗口里找「这里出错了（方法名）」。方法还没写，或写了但运行出错，都会出这句提示。
- 运行窗口里红字的 WARNING 和 GET、POST 记录是正常提示，不是出错。
- 提示 No module named 'flask'：PyCharm 窗口最下面靠右看一下解释器，选装了 Anaconda 的那一个；还不行，在 PyCharm 底部的 Terminal 里运行 `pip install flask`。

## 钥匙

钥匙写在工程根目录的 `.env` 里，也就是 app.py 所在的这个文件夹。在 PyCharm 左边的项目栏里，把 `.env.example` 复制一份，改名为 `.env`。
`.env` 里有两组，每组三项，都在讯飞开放平台控制台里你的应用下面：

- 三位伙伴念出声音：在「在线语音合成」里抄 APPID、APIKey、APISecret，填进 IFLYTEK_TTS 开头的三行。和项目二用的是同一套。
- 勾上 ✨AI 让星火回话：开通「星火认知大模型」以后，在讯飞开放平台控制台抄三项，填进 IFLYTEK_SPARK 开头的三行。

APIKey 和 APISecret 别填反。钥匙只写在 `.env` 里，不要写进 characters.py 或 services.py，也不要发给别人。
真的连讯飞要用两个库。项目二装过就不用再装；没装过，在 PyCharm 底部的 Terminal 里运行 `pip install websocket-client requests`。

没填钥匙时也能聊：念出来的是一段演示声音，✨AI 的回话换成伙伴的口癖。填好后重新运行 app.py。
